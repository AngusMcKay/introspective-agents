# Fernhill FX-28 combi boiler: user and installer manual (fictional)

The FX-28 is a 28 kW gas combination boiler providing central heating and instantaneous hot water. It must only be installed, serviced or repaired by a registered gas engineer.

System pressure should read between 1.0 and 1.5 bar on the front gauge when the heating is cold. When the system is hot the pressure may rise to around 2.0 bar, which is normal. The pressure relief valve opens at 3.0 bar.

Fault code F22 means low water pressure: the system pressure has fallen below 0.5 bar. Top up the pressure using the filling loop until the gauge reads 1.2 bar with the system cold, then close both filling loop valves fully and press reset.

Fault code F28 means ignition failure: the boiler attempted to light five times without detecting a flame. Check that other gas appliances work and that the gas supply is turned on, then press reset once. If F28 returns, call a gas engineer. Do not press reset repeatedly.

Fault code F61 means a fault with the main control board. This is not user serviceable.

If the pressure falls repeatedly and you need to top up more than once a month, the system probably has a leak or a failed expansion vessel. Have it inspected rather than continuing to top up.

The FX-28 should be serviced every 12 months. The expansion vessel pre-charge is 0.75 bar and should be checked at each service with the system drained down.
