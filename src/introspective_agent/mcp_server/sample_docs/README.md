These manuals are **fictional**. The products, specifications and fault codes are invented so the evals have known right answers, and so nothing here can be mistaken for real servicing data. Do not use any figure in them on a real boiler, vehicle or tool.

To use your own documents, put `.md` or `.txt` files in a folder and set `DOCS_DIR` to it. Converting PDFs to text is a good first extension.
